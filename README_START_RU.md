миграции базы данных, конфигурация и готовая сборка dist/.

## Структура

- ui/ — интерфейс, стили и интеграция с сервером.
- server/ — API МоегоСклада, вход сотрудников, безопасность и тесты.
- app/ — маршруты приложения.
- db/ и drizzle/ — схема и миграции D1.
- scripts/ и build/ — скрипты и конфигурация сборки.
- dist/ — уже собранная версия с исправлением UZ.
- .openai/hosting.json — идентификатор существующего сайта и привязки.
- .env.example — пустой шаблон переменных окружения.
- README.md — техническое описание поведения и ограничений.
- EXPORT_MANIFEST.json — перечень файлов и контрольные суммы SHA-256.

## Установка и сборка

Установите Node.js 24 LTS с npm. Откройте терминал в папке comfort-txt:

    npm run install:ci
    node scripts/generate-ui.mjs
    npm run build

Локальный режим разработки:

    npm run dev

Проверки серверной логики с подменёнными ответами МоегоСклада:

    node server/moysklad.test.mjs

После изменения файлов ui/ снова выполняйте generate-ui.mjs и сборку.

## Серверная среда

Проект использует Vinext/Cloudflare Workers, базу Cloudflare D1 (DB)
и хранилище R2 (BUCKET). Для полноценного отдельного развёртывания
нужно настроить эти привязки и применить миграции из drizzle/.
Обычное открытие index.html или размещение только статических файлов
не заменяет серверную часть.

В настройках среды задаются:
- MOYSKLAD_ACCOUNT_ID — UUID разрешённого аккаунта компании.
- CONNECTION_ENCRYPTION_KEY — секрет: 32 случайных байта в base64url.

Значения не входят в архив. Для текущего опубликованного сайта они
хранятся в настройках Sites. При обновлении этого сайта сохраните
существующие значения и привязки. Общий API-токен для входа не нужен:
сотрудник использует свой логин и пароль МоегоСклада.

Для публикации через Sites используйте штатный процесс проекта,
сохранив project_id и доступность сайта. Архив сам по себе не
обновляет опубликованную версию.

## Что не входит

Не включены node_modules, история Git, локальные кэши, временные файлы,
настоящие .env, токены, пароли и рабочие данные D1/R2.
Это полный исходный проект с готовой сборкой, а не резервная копия
рабочей базы и хранилища. Зависимости восстанавливаются по lock-файлу.

Исходники взяты из текущих файлов, включая ещё не опубликованные правки.
Успешная сборка уже была выполнена. Полноценная визуальная проверка
на реальных телефонах в этой среде не проводилась.
